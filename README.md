#### Connection string

`appsettings.json` съдържа и `Connection string`. Той се използва за връзка със сървъра, в който ще се съхраняват данните.

Това е стойността, която се подава на `DefaultConnection`:

```
Server=YOUR_SERVER_NAME;Database=icons;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true
```

Като на `Server` задаваш името на сървъра, който използваш. Представеният Connection string се използва за работа с Microsoft SQL Server. Ако използваш различна база данни, може да намериш правилния Connection string **[тук](https://www.connectionstrings.com/).**

Освен това, `appsettings.json` съдържа в себе си файл `appsettings.Development.json`, в който трябва да зададеш същия Connection string.

```
Server=YOUR_SERVER_NAME;Database=icons;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true
```

#### Работа с различна база данни

Давам пример за използване на `PostgreSQL`

1. Изтегляне на нужните пакети

Tрябва да инсталираш необходимите пакети за работа с PostgreSQL в .NET. Инсталирай следния NuGet пакет:

```
Npgsql.EntityFrameworkCore.PostgreSQL
```

2. Program.cs

При използване на различна база данни от Microsoft SQL Server трябва да промениш ето този фрагмент от `Program.cs`. 

```
var connectionString = builder.Configuration.GetConnectionString("SqlServerDev") ?? throw new InvalidOperationException("Connection string was not found.");

builder.Services.AddDbContext<ApplicationDbContext>(options =>
{
    options.UseSqlServer(connectionString);
});
```

В него е зададен Microsoft SQL Server. 

В случая давам пример с PostgreSQL. И при него фрагментът ще изглежда така:

```
var connectionString = builder.Configuration.GetConnectionString("PostgreDev") ?? throw new InvalidOperationException("Connection string was not found.");

builder.Services.AddDbContext<ApplicationDbContext>(options =>
{
    options.UseNpgsql(connectionString);
});
```

Стойността `SqlServerDev` се променя в `appsettings.Development.json`. Промяната му не е задължителна, но е правилно да се смени при работа с друга база данни.
А `UseSqlServer` се задава на `UseNpgsql`.

Съответно могат да се използват и други бази данни.

## 📚 Икони
- Страницата **икони** съдържа списък с всички създадени икони. Иконата съдържа снимка, заглавие и бутон, който я отваря. Освен това, след създаване на икона потребителят може да я редактира, ако прецени, че нещо в нея е сгрешено.
- Потребителят няма право да изтрива или редактира икони на други потребители.

> За разлика от него, администраторът и модераторите могат само да изтриват икони на други потребители, но не могат да ги редактират.

- В страницата е включен филтър, чрез който може да бъде променян реда, в който се показват иконите. Прилагат се следните филтри:
  - `DateAsc` - дата на създаване - възходящ ред (от най-старите към актуалните икони).
  - `DateDesc` - (това е филтърът по подразбиране) - дата на създаване - низходящ ред (от най-актуалните икони към старите).
  - `RatingAsc` - рейтинг - възходящ ред (от иконите с най-нисък рейтинг към висок).
  - `RatingDesc` - рейтинг - низходящ ред (от иконите с най-висок рейтинг към нисък).

## 🥸 Ревюта
- Под формата за добавяне на ревю се намира списък с ревюта (ако иконата изобщо има ревюта). В ревюто присъства профилната снимка и името на потребителя (за да знаеш кой ти дава ниски оценки), заглавието, описанието, датата на създаване, оценката, както и два бутона - за редактиране и изтриване на ревюто.
- Натискането на потребителската снимка и потребителското име отваря профила на конкретния потребител.
- Потребителите могат да редактират или изтриват собствените си ревюта. При редактиране се отваря модал, в който може да бъде променено заглавието или описанието, но не и оценката.

- В тази страница се показва цялата информация за потребителя. Освен профилна снимка и име, се показва рангът на потребителя. Той се определя от количеството еликсир, което потребителят притежава. Еликсир се получава по 3 начина:
  - **Създаване на икона** - носи 20 еликсир.
  - **Добавяне на ревю** - носи 5 еликсир.
  - **Един слънчев и прекрасен ден админът решава да те направи модератор** - носи 3001 еликсир (не се случва всеки ден).
- Когато рангът бъде натиснат, се показва скала с всички рангове и кога могат да бъдат придобити.
- <img width="2549" height="1344" alt="image" src="https://github.com/user-attachments/assets/0a3aabbe-68a0-4229-b4f8-785f2e637504" />

- Има и допълнителна информация като брой създадени икони и ревюта, както и дата на регистрация.
- След това се показва списък със създадените от потребителя икони. Те могат да бъдат отворени чрез бутона **преглед**. Ако потребителят не е качил икони, се показва съобщение.
- Под иконите се показва списък с ревютата, написани от потребителя. Отново, ако няма добавени ревюта, се показва съобщение.
